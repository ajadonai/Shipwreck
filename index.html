What is Shipwrecks?

If you're building with AI — Cursor, Copilot, Claude, ChatGPT — the code gets written fast. But fast doesn't mean safe. Your AI assistant doesn't flag missing auth, skipped error handling, or zero monitoring. It builds what you ask for and moves on.

Shipwrecks is the checklist for the gaps AI leaves behind. 37 mistakes across security, performance, code quality, DevOps, and UX that actually break production apps. Not theoretical. Not edge cases. The stuff that wakes you up at 3am.
